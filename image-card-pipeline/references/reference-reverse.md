# 参考图逆向

看到一张好图，先把"它为什么好"拆成可写的字段，再换成自己的主体重画一遍。核心不是"照着这张画"，而是**把参考图拆成能重画的字段**。

## 什么时候用

- 想复刻一种效果，但说不清它好在哪。
- 同一类画面要反复出，需要把"感觉"变成可复用的字段。
- 出图太随机，想少抽几张卡。

不适合：

- 已经定了真源和口径的常规出图——照卡走就行，不必每张都反推。
- 需要精确排版的商业文字（见「文字」）。
- 直接照抄别人的成图、角色或品牌（见「边界」）。

## 30 秒流程

参考图 → 反推七个字段 → 精简版试稿 → 只改要改的字段 → 哪块不对补局部参考图 → 定下后沉淀成模板或真源。

## 七个字段（5S + 2）

| 字段 | 写什么 | 最容易漏 |
|---|---|---|
| 0 用途与重点 | 这张图拿来干什么、第一眼落在哪 | 输出比例和用途 |
| 1 主体 Subject | 身份、体型、姿态、手部、视线、表情、服装层次、配饰、道具；多主体写清前后左右和遮挡 | 手部动作、视线方向 |
| 2 风格 Style | 写实/插画/胶片/3D、色彩倾向、质感、颗粒、锐度 | 介质和质感 |
| 3 镜头 Shot | 景别、机位高度与角度、焦段感、主体占比、留白、前中后景虚化 | 机位高度、留白 |
| 4 场景 Setting | 地点、时间、天气、空间结构、支撑主体的元素、可省略的元素 | 哪些元素是必需的 |
| 5 光照 Lighting | 光源位置、软硬、色温、明暗对比、轮廓光、阴影方向 | 光源方向、轮廓光 |
| 6 约束 Constraints | 必须保留什么、不要出现什么、冲突时谁优先 | 几乎所有人都漏这段 |
| 7 文字 Text（可选） | 逐条写内容、位置、字体、大小层级、颜色、描边；区分「画面文案」和「场景文字」 | 把字当成装饰 |

前六项写完，一张图的骨架就定了；文字单独处理，因为它最容易崩。

## 反推指令

给能看图的模型，一次只喂一张：

```
你是生图提示词工程师。请把这张参考图拆成可以直接用于生图的提示词，
按下面字段输出，不要省略字段；看不清的写“未确定”，不要编。

0. 用途与视觉重点：这张图适合做什么？第一眼落在哪？
1. 主体：身份/数量/年龄感/体型/姿态/手部/视线/表情/服装层次/配饰/道具；
   多主体写清前后左右与遮挡关系。
2. 风格：写实或插画、介质（照片/胶片/3D/绘画）、色彩倾向、质感、颗粒与锐度。
3. 镜头与构图：景别、机位高度与角度、焦段感、主体占比、留白位置、
   前中后景的清晰与虚化关系。
4. 场景与环境：地点、时间、天气、空间结构、支撑主体的元素、可省略的元素。
5. 光照与影调：光源位置、软硬、色温、明暗对比、轮廓光、阴影方向与过渡。
6. 约束：必须保留的特征；不要出现的元素；冲突时的优先级。
7. 文字（有字才写）：逐条列出内容、位置、字体风格、大小层级、颜色、描边，
   并注明是画面文案还是场景文字。

输出要求：
- 用自然语言分段，不要用表格；
- 主体和光照写细，风格和场景写准，不要堆形容词；
- 最后给一版 200 字以内的精简版，便于快速试稿。
```

有字时再追加一段文字专项：

```
如果参考图里有文字，请额外处理：
1. 先分类型：画面文案（标题、副标题、品牌名、海报语）/ 场景文字（招牌、墙面标语、书写文字）。
2. 文案和主体都重要时，把文案当“二号主体”，按 5S 分开写：
   内容与角色 / 字体粗细颜色描边质感 / 位置大小层级分行对齐。
3. 纯场景文字归到场景字段里，不要单列。
```

模型答「未确定」的地方由人补，不要让它猜。

## 从参考图里提取什么

- **主体**：身份、年龄感、体型、姿态、手部动作、视线、表情、服装层次、配饰
- **材质**：面料纹理、反光或哑光、磨损、透明度
- **色彩**：主色/辅色/点缀色、冷暖、饱和度、渐变
- **光线**：光源位置、软硬、色温、轮廓光、阴影方向
- **构图**：景别、机位高度、主体占比、留白、前中后景
- **空间**：多主体的前后左右、遮挡、透视
- **文字**：内容、字体、字号层级、颜色、描边、位置
- **风格**：写实/插画/胶片/3D、颗粒、锐度

## 三种参考图用法

| 用法 | 怎么给 | 什么时候用 | 注意 |
|---|---|---|---|
| 整图复刻 | 整张图当参考，反推后只换主体或场景 | 抄构图、抄光线、抄质感 | 别把原图的人物和品牌一起留下 |
| 局部参考 | 截一小块：皮肤、面料、logo、手部、文字 | 细节写不准时 | 图别太大，别带无关背景 |
| 空间参考 | 摆姿势工具或简单几何示意 | 多人站位、复杂动作、遮挡关系 | 图优先于文字描述 |

## 反推之后怎么改

- 一次只改一个字段，方便判断是哪句起的作用。
- 先用精简版试稿，再逐段补细节；不要一上来就整段长提示词。
- 手、脚、文字是最容易崩的三处，优先补参考图。
- 主体段、光线段、约束段分开改，别混在一起改。
- 文字多就拆开做：先出无字底图，再分段生成文字，最后用代码做像素合成；字数越多越容易错，抽卡成本也越高。

## 自检五条

1. 把主体换掉，这套描述还成立吗？
2. 文字有没有编造？
3. 光照方向前后一致吗？
4. 手和脚有没有写到？
5. 约束段写了吗？

## 边界

- **版权**：借结构、借光线、借构图可以，别借具体角色、品牌和成图。
- **精确文字**：扩散模型是"画得像字"，不是排版；商用零错时必须拆开合成。
- **复杂空间**：纯文字描述有上限，必须上参考图。
- **模型差异**：不同模型对长提示词、参考图数量的容忍度不同，换模型要重新标定。
- **参考图外发**：参考图优先内联；要上传图床时确认素材可以离开本机。

## 接进本 Skill 的走法

按四层分工放东西，别把反推结果整段抄进卡：

| 反推出的东西 | 放哪 |
|---|---|
| 长相（脸、体型、固定造型） | `sources.yaml`（真源层），用 `promote --as character:` |
| 可复用的风格、光线、构图口径 | `prompt-zone/`（口径层），或 `promote --as template:` |
| 这一镜独有的动作、站位、表情 | 卡里的 `action` / `composition` / `hard_rules` |
| 局部细节参考（皮肤、面料、文字） | 卡的 `refs.files`，或真源里的 face / 细节图 |

短效路线：`inspire add` 存参考图 → 反推七字段 → 精简版当 `--idea` 试几张（`sketch`）→ 定下后 `promote` 成真源或模板。

长效路线：卡里勾 `example/03_five_s#完整结构` 和 `example/04_constraints#完整`，`refs` 指局部参考图，`hard_rules` 写这一镜的禁止项。

## 示例：把一张参考图变成一张卡

```yaml
id: 01-01
title: 参考图复刻
aspect: 1536x1024
pack: 测试/参考图复刻
refs:
  roles: ["overall look, composition and lighting of the reference"]
  files: [inbox/reference.png]          # 整图；局部细节另加 files
prompt_templates:
  - example/03_five_s#完整结构
  - example/04_constraints#完整
action: >-
  The same scene as the reference image, with the subject replaced by the
  registered character; keep the framing, camera height and light direction.
hard_rules:
  - "No text, watermark or signature anywhere in the frame."
checklist: ["构图和参考图一致", "光源方向一致", "没有多余文字"]
```

反推出来的七段可以填进 `03_five_s` 的变量，也可以直接写进 `extra_prompt`；两种都行，别同时写，免得重复。

## 文件位置

- 本文件：方法、反推指令、清单、边界。
- `templates/prompt-zone/example/03_five_s.md`：英文 5S 骨架，可勾选、会拼进提示词。
- `templates/prompt-zone/example/04_constraints.md`：英文约束段，可勾选。

反推指令是给模型看的中文指令，放本文件；`prompt-zone` 的解析器只收英文正文段，放进去会被丢掉，所以不往那里放。
