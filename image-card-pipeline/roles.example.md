# 角色对应的工具（照这个填，存成同目录的 roles.md）

SKILL.md 只说「哪个角色做哪件事」。具体用哪个 AI、怎么调用，写在这里。
没有 roles.md 时，四个角色都由主模型自己做，规矩照旧。

| 角色 | 填你用的是谁 | 怎么调用 |
|---|---|---|
| 主模型 | 你和它对话的那个 AI（如 Claude Code、Codex、Cursor 里的模型） | — |
| 判断子代理（可选） | 主模型能派出去、要下判断的子任务交给谁；没有就留空，由主模型自己做 | 例：Claude Code 的 Agent 工具 |
| 文字助手（可选） | 便宜快的模型，接不看图的杂活：批量建卡、改字段、写测试、跑命令、查资料 | 例：`<你的命令行> -p "<任务>"` |
| 看图助手（可选） | 能看图的便宜模型，接看图的杂活：批量描述图、按清单粗筛、打标签 | 例：`<你的命令行> -p "<任务，附图片绝对路径>"` |

填的时候守两条：
1. 看图下判断（挑参考、自审、提议要哪几张、归因）只归主模型；看图助手的结论不算数。
2. 文字助手、看图助手交回的东西，主模型核对过才算数。

`review --by` 只收 `project.yaml` 里 `rules.reviewers` 列的名字（默认 `[claude, human]`）。
`claude` 在这里就是「主模型」的意思：主模型不是 Claude 也照旧记 `claude`，最省事。
真要换名字，就把名单改成比如 `[gpt, human]`，之后每次 `review` 都带上 `--by gpt`。
